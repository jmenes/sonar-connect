# Sonar Connector (WordPress Plugin)

Conector oficial de WordPress para la suite de herramientas **Sonar**. Diseñado para ofrecer máxima velocidad, seguridad criptográfica y total independencia sin necesidad de tocar código.

## Características

- ⚡ **SEO Multi-Plugin**: Soporte nativo para Rank Math, Yoast SEO, All in One SEO, SEOPress y fallback a extractos/contenido.
- 🖼️ **Gestión de Medios**: Auditoría y optimización de textos alternativos (ALT), dimensiones y peso de imágenes.
- 🧹 **Caché Inteligente**: Purgado automático compatible con LiteSpeed Cache, WP Rocket, W3 Total Cache, WP Super Cache, Autoptimize y Redis Object Cache.
- 🔒 **Seguridad Criptográfica Asimétrica**: Autenticación por firma Ed25519 con marcas de tiempo (timestamp) y mitigación de ataques de repetición (nonce).
- 🔄 **Auto-Updater Nativo**: Se actualiza directamente desde el panel de Plugins de WordPress mediante GitHub Releases.

## Instalación

1. Descarga el archivo `sonar-connector.zip` desde la sección [Releases](https://github.com/jmenes/sonar-connect/releases).
2. En tu WordPress, ve a **Plugins > Añadir nuevo > Subir plugin**.
3. Selecciona el archivo `.zip`, instálalo y actívalo.
4. Conecta tu sitio desde Sonar introduciendo la URL de WordPress y la clave de aplicación o verificación.

## Actualizaciones automáticas

El plugin comprueba automáticamente si existen nuevas versiones publicadas en este repositorio y te avisará en tu panel de administración de WordPress como cualquier plugin oficial.
